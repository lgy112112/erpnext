# Change Log 模块（历史版本变更日志）

## 概述

`change_log/` 保存 ERPNext 历史版本的发布说明与功能更新记录（Markdown 文档）。

这不是业务流程运行时代码，但对 LLM 有两个实际用途：
- 理解某功能在历史版本中的演进背景
- 编写迁移说明/升级说明时参考既有风格

## 规模（当前仓库）
- 12 个目录（含 `current`）
- 约 67 个 Markdown 文件

## 目录结构（示例）
- `change_log/current/` — 当前变更说明草稿/入口
- `change_log/v5/` ... `change_log/v15/` — 历史版本日志

## 何时需要加载

- 你在做跨版本兼容或升级迁移方案
- 需要判断某行为是“新改动”还是历史既有行为
- 需要为业务流程变更补充 release note

## 注意

- `change_log/` 不能替代源码；它提供的是变更背景，不是当前运行逻辑的权威来源。
