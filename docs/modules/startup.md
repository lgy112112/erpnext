# Startup 模块（启动上下文与通知）

## 概述

`startup/` 负责登录后启动阶段的一部分数据准备与体验逻辑，例如：
- boot 数据扩展
- 通知相关逻辑
- 首页/看板筛选与排行榜

当你修改业务流程并新增状态、提醒或首页卡片数据时，需要检查这里。

## 规模（当前仓库）
- 5 个 Python 文件

## 关键文件
- `startup/boot.py` — 启动数据注入/扩展入口
- `startup/notifications.py` — 通知相关逻辑
- `startup/leaderboard.py` — 排行榜数据
- `startup/filters.py` — 启动筛选逻辑

## 修改业务流程时何时需要看这里

- 新增单据状态后，通知计数/提醒需要同步
- 首页工作台统计要展示新状态或新单据
- 启动上下文中缓存/预取字段需要更新

## 常见风险

- 后端状态新增但通知未更新，用户看不到提醒
- 首页数字卡片统计口径仍使用旧状态集合
