# Templates 模块（邮件/打印/Web 模板）

## 概述

`templates/` 存放 ERPNext 的模板与页面逻辑，包括：
- 邮件模板
- 打印格式模板
- Web 页面模板
- 表格/列表模板片段
- 页面配套 Python/JS/CSS

业务流程改动若影响：
- 邮件通知内容
- 打印格式字段
- Portal / Web 页面展示字段

通常需要同步检查本目录。

## 规模（当前仓库）
- 约 73 个文件
- 约 50 个 HTML 模板
- 18 个 Python 文件

## 关键子目录

### `templates/pages/`
自定义页面模板与处理逻辑（常见组合：`*.html + *.py`，有时带 `*.js`）

### `templates/emails/`
邮件通知模板（例如项目摘要、预约确认）

### `templates/print_formats/`
打印格式相关模板与 includes

### `templates/includes/`
可复用模板片段（订单行、税额分解、RFQ 片段等）

### `templates/form_grid/`
表单内表格模板（影响前端渲染）

## 修改业务流程时必须检查的点

1. 新字段是否需要在模板中展示
2. 状态/金额文案是否需要同步
3. Portal 页面使用的 include 片段是否复用旧字段
4. 打印模板是否依赖旧字段名或旧计算结果

## 常见风险

- 后端字段已改，但邮件/页面模板仍引用旧字段
- Portal 页面显示与后台单据状态不一致
- 打印模板税额明细与新税费逻辑不匹配
