# Locale 模块（本地化翻译资源）

## 概述

`locale/` 存放 ERPNext 多语言翻译资源（`*.po`）与模板（`main.pot`）。

当业务流程修改涉及用户可见文案（状态名、按钮文案、提示信息、页面文本），并且你希望多语言体验保持一致，需要检查这里。

## 规模（当前仓库）
- 32 个 `.po` 语言文件
- 1 个 `main.pot` 模板文件

## 作用

- 为 UI 文案、错误提示、页面文本提供翻译
- 支撑国际化部署场景

## 修改业务流程时何时需要关注

- 新增或修改用户可见字符串
- 状态值文案变化需要同步翻译
- Web/Portal 页面新增文本

## 常见风险

- 代码逻辑已改，但多语言环境显示旧文案或英文回退
- 状态文案变化后报表/页面翻译未同步

## 备注

- `locale/` 是资源层，不决定业务逻辑；当前行为以源码为准。
